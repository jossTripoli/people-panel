# People Panel
User management ui for an application administrator

## Approach / Decisions
I’m approaching this project differently from my usual design process. I believe that good frontend design starts with being informed: understanding the problem, business objectives, brand identity, competition, users etc before building a solution. My approach is influenced by my experience with the Design Thinking process (Empathize, Define, Ideate, Prototype, and Test) which I learned working at Lehigh Human Computer Interaction and Social Computing Lab and NSF I-Corps programs.
